# NEXLIX · WATCH MORE • LIVE MORE

واجهة عربية (RTL) كاملة لمنصة بث ترفيهي — مباريات مباشرة، تلفزيون، أفلام ومسلسلات — بتصميم سينمائي أسود/أحمر وتوهّج نيون.

## التشغيل

كل شيء داخل ملف واحد: **`index.html`**.

- افتح الملف مباشرة في المتصفح (نقرة مزدوجة) — يعمل فوراً.
- أو شغّل خادماً محلياً (مفضّل، لأن زر «عرض المزيد» عبر HTMX يحتاج HTTP):

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## التقنيات

| التقنية | الاستخدام |
| --- | --- |
| HTML5 + CSS3 | البنية والتنسيق، مع CSS مخصص للتوهّج والحركات |
| Tailwind CSS (CDN) | الشبكة (Grid) والتجاوب عبر `md:` / `lg:` |
| HTMX (CDN) | «عرض المزيد» عبر `hx-get` + `hx-select` + `hx-swap` |
| Vanilla JS | القائمة الجانبية، السلايدر، البحث الحيّ، ظهور العناصر |
| Font Awesome 6 | كل الأيقونات |
| Google Fonts | خط **Tajawal** للعربية و**Montserrat** لشعار NEXLIX |

## أقسام الصفحة

1. **الشريط العلوي** — شريط أدوات عائم في **يسار** الصفحة يحتوي **3 أيقونات فقط** (Flexbox بمسافات متساوية): القائمة · البحث · الوضع الليلي، مع لوحة بحث منسدلة تحته. لا شعارات ولا نصوص.
2. **الهيرو (سلايدر)** — 3 شرائح بصور سينمائية، بانر طولي خاص بالهاتف، نقاط تحكم وأسهم وتشغيل تلقائي وسحب باللمس.
3. **شريط المميزات** — 4 أيقونات مع فواصل عمودية.
4. **أقسام المنصة** — 4 بطاقات بصور، تدرّج داكن، سهم أحمر دائري وتأثيرات Hover.
5. **الأكثر مشاهدة** — شريط بطاقات أفقي + بحث فوري + زر «عرض المزيد».
6. **التذييل** + **شريط تنقل سفلي ثابت للهاتف** (الرئيسية / مباشر / تحميلات / إعدادات).

## الملفات

- `index.html`: الموقع كامل (HTML + CSS + JS).
- `assets/nexlix-logo.webp`: شعار NEXLIX بخلفية شفافة (803×254) المستخدم في وسط الهيرو.
- `.nojekyll`: لإخبار GitHub Pages بعدم معالجة الملفات عبر Jekyll.

## الوضع الليلي / الفاتح

أيقونة القمر في شريط الأدوات تبدّل بين الوضع الليلي (الافتراضي) والوضع الفاتح، ويُحفظ الاختيار في `localStorage` ويُطبَّق قبل أول رسم لمنع الوميض.

## ملاحظات

- الصور نائبة من **Unsplash** عبر روابط CDN، وكل بطاقة لها تدرّج خلفي بديل في حال تعذّر تحميل الصورة.
- صور المشاهير/الشخصيات (محمد صلاح، سبايدرمان، جون سنو…) محمية بحقوق نشر؛ استبدل روابط `src` بأعمال مرخّصة عند النشر.
- HTMX هنا للتفاعلية الخفيفة فقط؛ عند فتح الملف عبر `file://` يعمل زر «عرض المزيد» ببديل محلي (JavaScript) تلقائياً.
- عند النشر الفعلي يُفضّل بناء Tailwind محلياً بدل CDN، وربط البث عبر Backend مرخّص.
